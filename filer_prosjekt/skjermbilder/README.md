# Skjermbilder fra produksjon — Vedlegg F

Denne mappen inneholder skjermbilder fra `https://www.studwize.page` slik appen fremstod ved innleveringstidspunktet. Skjermbildene brukes i Vedlegg F i bachelorrapporten og kompletterer den tekstlige beskrivelsen i kapittel 3.3 og 4.6.

## Status

- [ ] Skjermbildene er ikke tatt enda. Mappen er opprettet som plassholder.
- Skjermbildene bør tas i én økt, samme dato, og med konsekvent vindusstørrelse (anbefalt: 1440×900 for desktop, 390×844 for mobil).
- Anonymiser eventuell test-bruker-data i skjermbildene (navn, e-post, Canvas-token).

## Filnavn å bruke

Bruk dette mønsteret slik at filnavnene matcher figurnummereringen i rapporten:

| Filnavn | Hva som skal vises |
|---------|-------------------|
| `vedlegg-f-01-forside-innlogget.png` | Dashboard / forsiden med Canvas-data innlogget |
| `vedlegg-f-02-chat-canvas-kontekst.png` | KI-chat med svar og synlig svarkilde-badge |
| `vedlegg-f-03-kunnskapsbase-oversikt.png` | Kunnskapsbase med opplastede dokumenter |
| `vedlegg-f-04-kvissoppgave-generator.png` | Quiz-generator med valg av antall/vanskelighet |
| `vedlegg-f-05-arbeidsplan-ukeplan.png` | Arbeidsplan / ukeplan med KI-genererte økter |
| `vedlegg-f-06-innstillinger.png` | Innstillinger (språk, varsler, personvern) |
| `vedlegg-f-07-eksport-dialog.png` | Eksport-dialog (Markdown/PDF/Word/Notion) |
| `vedlegg-f-08-mobilvisning-chat.png` | Mobilvisning av chat-grensesnittet |
| `vedlegg-f-09-mork-modus.png` | Samme grensesnitt i mørk modus (dark:-variant) |

## Bildetekster

Hver figur skal ha bildetekst i Word på dette mønsteret:

> Vedlegg F-X: [Beskrivelse]. Hentet fra `https://www.studwize.page` på leveringsdato.

## Etter at skjermbildene er tatt

1. Lim inn PNG-filene i denne mappen med navnene over.
2. Sett dem inn i Word-dokumentet under Vedlegg F.
3. Marker av sjekklisten øverst i denne filen.
4. Anonymiser igjen før commit hvis bildene viser test-data.
